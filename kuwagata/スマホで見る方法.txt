スマホで見る方法（2通り）
========================================


■■ 方法A：パソコンが手元にない場合（今すぐ・おすすめ） ■■

このフォルダは OneDrive の Desktop 配下にあります。
＝ すでに masao さんのクラウドに同期済みです。
　　こちらで何かする必要はありません。

【スマホでの手順（Android / Chrome）】

 1. スマホの「OneDrive」アプリを開く
 2. 「ファイル」→「デスクトップ（Desktop）」→「kuwagata」
 3. 「index.html」をタップ
 4. プレビューは出ません。右上の「…」→「開く」または
    「ダウンロード」を選ぶ
 5. 通知バーの「ダウンロード完了」をタップ →
    「Chrome で開く」を選択
 6. 表示されたら完了。ブックマークしておく

 ※ 一度ダウンロードすれば、以降は完全にオフラインで使えます
   （電波ゼロでも動きます）
 ※ この方法だと「ホーム画面に追加」でのアプリ化はできません。
   また「チェックリスト」の記録が
   ブラウザを閉じると消える場合があります。
   → 図鑑・安全情報・クイズは すべて問題なく使えます。

【iPhone の場合】
 OneDrive アプリ →「…」→「別のアプリで開く」→
 「ファイル」に保存 → ファイルアプリから Safari で開く
 （iPhone は file:// の扱いが厳しいので、
　 うまくいかない場合は 方法B を推奨）


■■ 方法B：パソコンが使える場合（本命・完全アプリ化） ■■

GitHub Pages に置くと、
・ホーム画面にアイコンとして追加できる
・Service Worker が効いて 完全オフライン動作
・家族全員のスマホで URL を共有するだけ
になります。

【手順】

 1. パソコンで https://github.com/masaosatake1127-sudo/private-apps
    を開く
 2. 「Add file」→「Upload files」
 3. このフォルダ（kuwagata）ごと ドラッグ＆ドロップ
    ※ 中身は次の6ファイル：
       index.html / manifest.json / sw.js /
       icon-192.png / icon-512.png / apple-touch-icon.png
 4. 「Commit changes」
 5. リポジトリの Settings →  Pages →
    Source を「Deploy from a branch」／ Branch を main ／ root
    にして Save（すでに設定済みなら不要）
 6. 数分待つと、次の URL で開けます：

    https://masaosatake1127-sudo.github.io/private-apps/kuwagata/

 7. スマホの Chrome でその URL を開く
    → メニュー →「ホーム画面に追加」
    → アイコンが追加され、アプリとして起動できます
    → 一度開けば 以降はオフラインでも動きます

 ※ Service Worker のキャッシュ名は "kuwagata-" で始まります。
   他のアプリ（献立・台風ウォッチ 等）のキャッシュには
   一切触れない作りにしてあります。


========================================
中身（全6ファイル）
========================================
 index.html ............ 本体（これ単体でも完全に動きます）
 manifest.json ......... アプリ化の設定
 sw.js ................. オフライン動作（GitHub Pages 用）
 icon-192.png .......... ホーム画面アイコン
 icon-512.png .......... ホーム画面アイコン（大）
 apple-touch-icon.png .. iPhone 用アイコン

※ index.html は外部読み込みが一切ありません。
  イラストは全て内蔵SVG。写真は使っていません。
  この1ファイルだけでも 完全に動作します。
