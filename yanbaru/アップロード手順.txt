=======================================================
 奥やんばるの里プラン ― GitHub へのアップロード手順
=======================================================

このフォルダ（yanbaru）ごと、既存リポジトリ
  masaosatake1127-sudo/typhoon-chatan
のトップに追加します。既存の台風ウォッチには影響しません。

--- 手順（ブラウザだけで完結）---------------------------

1. https://github.com/masaosatake1127-sudo/typhoon-chatan を開く

2. 「Add file」→「Upload files」をクリック

3. このフォルダ（yanbaru）を、点線の枠のなかへ
   ★フォルダごとドラッグ＆ドロップ★ する
   → 6つのファイルが yanbaru/ の中に入った状態で表示されればOK
     ・index.html
     ・manifest.json
     ・sw.js
     ・icon-192.png
     ・icon-512.png
     ・icon-512-maskable.png

4. 下の「Commit changes」を押す

5. 2〜3分待ってから、スマホのChromeで次のURLを開く

   https://masaosatake1127-sudo.github.io/typhoon-chatan/yanbaru/

   ※末尾のスラッシュ（/）まで入れてください

6. Chromeのメニュー（右上の ⋮ ）→「ホーム画面に追加」
   → たき火のアイコンが付いたショートカットができます

7. ★重要★ 出発前に必ず動作確認
   機内モードにしてから、ホーム画面のアイコンで開いてみる。
   開けばオフライン準備完了です。
   開けない場合は、機内モードを解除して手順5をもう一度開き、
   30秒ほど待ってから再度お試しください。

--- 更新したくなったら -----------------------------------

index.html を差し替えるだけでOKです。
ただしスマホ側に古いキャッシュが残るため、
sw.js の中の

   const CACHE  = PREFIX + 'v1-2026-08-07';

の 'v1-2026-08-07' の部分を 'v2-2026-08-10' のように
書き換えてから両方アップロードしてください。
古いキャッシュは自動で削除されます。

--- うまくいかないとき -----------------------------------

・404になる → 2〜3分待つ。GitHub Pagesの反映には時間がかかります
・アイコンが出ない → 一度ショートカットを削除し、
  Chromeでページを開き直してから、もう一度「ホーム画面に追加」
・古い内容が出る → Chrome設定 → サイトの設定 → 保存されている
  データ から該当サイトのデータを削除して開き直す
